## Key features

### Modern cryptography

Strong, opinionated defaults built around modern ciphers and protocols.

### Secure remote access

Create private tunnels to reach VM services without opening them to the public internet.

### Simple peer model

Configure explicit peers and routes for clear, auditable connectivity.
