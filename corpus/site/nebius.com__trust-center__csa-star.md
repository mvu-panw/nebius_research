CSA STAR Level 1 is based on a self-assessment. Nebius completed the CSA Consensus Assessments Initiative Questionnaire (CAIQ), which maps our security controls against the CSA Cloud Controls Matrix (CCM).

The completed assessment is published in the CSA STAR Registry.

## Questions and answers

What is CSA STAR Level 1?

CSA STAR stands for Security, Trust, Assurance, and Risk, a cloud assurance program created by the Cloud Security Alliance (CSA). It is designed to help cloud service providers demonstrate the security of their services and help customers assess cloud security risks.

At Level 1, the provider completes the Consensus Assessments Initiative Questionnaire, which is based on the CSA Cloud Controls Matrix (CCM). The completed assessment is published in the public CSA STAR Registry.

It demonstrates transparency about cloud security controls and alignment with CSA cloud security best practices.

What Nebius products are within the scope of assessment?

Nebius AI Cloud infrastructure and platform services. It also includes the security, operational, and governance controls that support the delivery and protection of these services.

Who manages the CSA STAR Registry?

The CSA STAR Level 1 listing is published by the Cloud Security Alliance (CSA).

Nebius is listed in the CSA STAR Registry after completing the Level 1 assessment.
