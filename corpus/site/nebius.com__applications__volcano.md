# Volcano
by Volcano
Orchestration

Volcano is a Kubernetes native batch scheduling system designed to efficiently manage high performance computing (HPC), machine learning (ML), deep learning, and other data intensive workloads. It extends Kubernetes' batch scheduling capabilities, offering optimized resource sharing, job lifecycle management, and advanced scheduling features.Deploy on Nebius
