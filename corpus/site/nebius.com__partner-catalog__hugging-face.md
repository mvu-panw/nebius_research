# Hugging Face

Models
Development

Nebius is a supported inference provider on the Hugging Face Hub. Developers can run chat completions on open LLMs and VLMs, feature extraction, and text-to-image directly from Hugging Face, served by Nebius Token Factory and accessed through the Hub’s familiar APIs and billing. The integration puts Nebius production inference behind the models where millions of developers already work.
