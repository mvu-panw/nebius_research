## Key features

### Natural-language video search

Ask questions about uploaded or stored video streams through the VSS agent and UI.

### Video question answering

Analyze clips with NVIDIA vision-language models or compatible remote model endpoints.

### Kubernetes deployment

Deploy the VSS base profile with Helm-managed application, data, VST, and model-serving components.

Use local in-cluster model serving or connect to compatible remote LLM and VLM endpoints.
