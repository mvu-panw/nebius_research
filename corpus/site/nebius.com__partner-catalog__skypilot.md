# SkyPilot

Infrastructure
Orchestration

SkyPilot is a system to run, manage, and scale AI workloads on any AI infrastructure.

Nebius AI Cloud is a supported SkyPilot cloud, and Nebius offers a Managed SkyPilot API Server — a fully managed control plane deployed in one click from the Nebius console. Teams use SkyPilot to launch training, batch, and serving jobs on Nebius GPUs with automatic provisioning and scaling, documented at docs.nebius.com. Joint technical guides cover serving Llama models with SkyPilot and SGLang on Nebius.
