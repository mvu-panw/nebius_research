## Native capabilities for document intelligence

What Token Factory covers across the document pipeline — from parsing and extraction to classification and search.

## Parse and understand documents

Analyze layouts, extract tables, and run OCR with Qwen2.5-VL and Nemotron Nano 2 VL via /v1/chat/completions.

## Structured extraction

Pull fields, entities, and tables into typed schemas with JSON mode and structured output via the Tool use API.

## Document classification

Classify document types, route to the right extraction schema, and trigger downstream workflows.

## Search and index documents

Create semantic document search with BAAI/bge-en-icl via /v1/embeddings. Pair with Qdrant or Weaviate.

## Process documents at scale

Orchestrate batch pipelines on Managed Kubernetes. Distribute high-volume workloads with Anyscale/Ray.

## Store extracted data

Managed PostgreSQL for extracted fields and metadata. Object Storage for raw documents and processed outputs.
