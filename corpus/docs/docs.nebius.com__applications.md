# Applications in Nebius AI Cloud

With applications in Nebius AI Cloud, you can deploy third-party software on [Managed Service for Kubernetes®](https://docs.nebius.com/kubernetes/index.md) clusters to streamline your AI and ML workflows.

You can browse applications by name or category in the Applications marketplace. Each application page shows how to deploy the application on a Managed Kubernetes cluster.

For hosted interactive environments without a Kubernetes cluster, you can also use [Serverless AI Devlabs](https://docs.nebius.com/serverless/devlabs/manage.md).
