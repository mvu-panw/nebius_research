# Kubernetes Operator for Apache Flink®
by Apache
Orchestration

Apache Flink® is a stream processing framework that enables you to build robust, scalable, and high performance applications. Complex event processing, pattern recognition, and windowed aggregations with Flink’s extensive set of APIs and libraries empower you to derive meaningful insights from your streaming data. The Apache Flink Kubernetes Operator allows you to manage Apache Flink applications and their lifecycle using native k8s tooling like kubectl. This includes deploying and monitoring deployments in Application Mode and Session Mode, as well as working with logs and metrics.Deploy on Nebius
