# Qdrant in Nebius AI Cloud

Qdrant is available as a Kubernetes application in the `eu-north1` and `us-central1` [regions](https://docs.nebius.com/overview/regions.md). You deploy it on a [Managed Service for Kubernetes®](https://docs.nebius.com/kubernetes/index.md) cluster.

## About the application

[Qdrant](https://github.com/qdrant/qdrant) is an open-source vector database and similarity search engine. It is designed for handling high-dimensional vector data efficiently. It enables fast and scalable semantic search, recommendation systems and neural information retrieval through vector similarity.

For more details, see the [application page](https://console.nebius.com/applications) in the web console.

Qdrant is available under the [Apache 2.0 license](https://github.com/qdrant/qdrant/blob/master/LICENSE).

## Getting started

To use the Qdrant application, [deploy it on a Kubernetes cluster](https://docs.nebius.com/applications/deploy.md) and [connect to it](https://docs.nebius.com/applications/qdrant/connect.md).
