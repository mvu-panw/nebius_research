# Data portability in Nebius AI Cloud

In compliance with the European Union regulations such as the [General Data Protection Regulation](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng) (GDPR) and the [Data Act](https://eur-lex.europa.eu/eli/reg/2023/2854/oj/eng), you can exercise your right to data portability. This means that you can export personal data (under the GDPR and the Data Act) and non-personal data (under the GDPR) that you store in Nebius AI Cloud, allowing you to move the data to other cloud providers or data controllers and set up multi-cloud architectures.

To export data, you can use interfaces and tools from Nebius AI Cloud or third parties. For details on how to export data, see the following instructions:

* **Compute disks and shared filesystems:** [Exporting data from Compute disks and shared filesystems](https://docs.nebius.com/compute/storage/export.md)
* **Object Storage buckets:** [Uploading and downloading objects in Object Storage](https://docs.nebius.com/object-storage/objects/upload-download.md)
* **Managed Service for PostgreSQL clusters:** [Migration from or to a Managed Service for PostgreSQL® cluster](https://docs.nebius.com/postgresql/data-transfers/migrate-data.md)
* **Container Registry registries:** [Copying images to and from registries in Container Registry](https://docs.nebius.com/container-registry/images/copy.md)
* **Managed Service for MLflow clusters:** [Exporting data from Managed Service for MLflow clusters](https://docs.nebius.com/mlflow/clusters/export-data.md)
* **Monitoring metrics:** [How to view metrics in Prometheus](https://docs.nebius.com/observability/metrics/prometheus.md)
* **Logging logs:** [How to query logs with LogCLI](https://docs.nebius.com/observability/logs/logcli.md)
* **Audit Logs events:** [How to export audit events to Object Storage](https://docs.nebius.com/audit-logs/events/export.md)
* **Billing data:** [Exporting usage data as CSV in Nebius AI Cloud](https://docs.nebius.com/signup-billing/usage/export.md)

If you have issues with exporting your data or questions about data portability and data management in general, you can submit a [Data Subject Request](https://docs.nebius.com/overview/support.md#data-subject-requests) (DSR) to Nebius AI Cloud support.
