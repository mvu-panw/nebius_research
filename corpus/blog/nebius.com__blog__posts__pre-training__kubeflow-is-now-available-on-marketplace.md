# Kubeflow: now available on Marketplace

Source: https://nebius.com/blog/posts/pre-training/kubeflow-is-now-available-on-marketplace

Skip to main content

Kubeflow provides an ML stack for Kubernetes, consisting of TensorFlow, Jupyter notebooks, and other ML tools. With Kubeflow, data scientists and engineers can build, train and deploy machine learning models in a consistent and reproducible manner across different environments. Kubeflow enables you to run end-to-end ML workflows on Kubernetes, from data preparation to model training and serving, using the same infrastructure and tools. It simplifies the deployment process by abstracting away the complexities of managing Kubernetes resources, allowing you to focus on developing and iterating ML models.

Kubeflow is obviously quite popular among the clients of Nebius AI. One example is Recraft, a gen AI company that used a PyTorch + Kubeflow combination to train its 20B foundational model from scratch on our platform.

You can deploy Kubeflow in your Managed Kubernetes clusters using this Marketplace product. It deploys Kubeflow through deployKF — make sure, though, that you already have NVIDIA GPU Operator and Argo CD installed.
