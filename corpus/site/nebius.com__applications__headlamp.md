# Headlamp
by Kubernetes SIGs
Observability

Headlamp is a modern, extensible Kubernetes web UI built by the Kubernetes SIGs community. It provides a clean interface for exploring and managing cluster resources, with a plugin system for customization. Headlamp supports multi-cluster management, container terminal access, log streaming, and resource editing — all through a responsive web interface accessible via a secure tunnel endpoint.Deploy on Nebius

## Key features

### Modern, responsive UI

Clean interface for navigating cluster resources including Pods, Deployments, Services, and more.

### Plugin system

Extend functionality with community and custom plugins for additional views and actions.

### Container terminal and logs

Open terminal sessions and stream logs from running containers directly in the browser.

### Secure tunnel access

Accessible via a secure HTTP/2 tunnel endpoint — no port forwarding or public IP required.
