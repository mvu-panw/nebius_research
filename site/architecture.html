Backbone and DC domains (the post-mortem)

On September 3, 2025, us-central1 went down for 1h45m. A routing-policy change had created a latent conflict between the Backbone and Data Center network domains. A later "security infrastructure extension", described as "new Firewall nodes onboarding", triggered route recomputation and a persistent routing loop on the inter-facility path. Confirmed post-mortem

  • Nebius operates its own backbone, with firewalls at the boundary between backbone and DC.
  • us-central1 services depended on eu-north1 (Finland) for the console, tenant registration and quotas, and geo-IP load balancing kept sending users to the broken endpoint.
  • Planned fixes include stricter split-horizon between routing domains, pre-deployment routing simulation, churn alerting, geo-DNS failover and regionalized control planes.
  • Implication: any firewall proposal will be judged on how it interacts with routing. Make the insertion design the first slide. Inferred

VPC: what tenants get

  • The object model is network → subnet → pool → allocation, plus routing tables and DNS zones. IPv4 only. docs
  • Security groups have been GA since February 2026. They are L3/L4 (TCP, UDP, ICMP or any), stateful by default, with up to 60 rules per group, 8 groups per NIC, and up to 8 CIDRs and 8 ports per rule. A default group is always attached. docs limits
  • Egress: the default egress gateway NATs to the VM's public IP or a shared dynamic pool. Projects get 3 public IPv4 addresses by default. docs
  • Custom route tables (since September 2025) let a VM act as a NAT or appliance gateway for chosen subnets. Traffic within a network always routes directly and can't be steered. docs
  • Site-to-site VPN: an open-source, VM-based IPsec gateway (IKEv2) from Nebius Professional Services, on GitHub, since March 2026. There is no managed VPN. docs
  • Tunnels: expose services through an outbound agent with no inbound ports. Limits are 120 Mbps per tunnel, 600 Mbps per project and 8 Gbps per region. GA in all regions in October 2026. docs

Isolation and platform security

  • GPU fabric: each GPU cluster gets its own InfiniBand P-Key on a shared physical fabric. docs
  • Tenancy: tenants, then projects (one per region), with IAM groups and roles. Customers can create their own tenants for separate billing and isolation (since September 2025). docs
  • Services: Audit Logs, KMS and SecretStash in every region. Managed Kubernetes control planes can be restricted to allowed CIDRs. regions
  • Customer workload security: a CrowdStrike Falcon integration (March 2026). Reported
  • No native L7 inspection, IPS, URL filtering or managed WAF in the VPC docs. Inferred from the docs crawl
