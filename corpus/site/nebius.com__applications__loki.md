# Grafana Loki
by Grafana Labs
Observability

Grafana Loki is a horizontally scalable, highly available, multi-tenant log aggregation system. It supports a wide range of log formats, sources, and clients, and allows formatting logs at query time rather than at ingestion. Loki only indexes the metadata of a log line, which significantly reduces storage requirements and simplifies operations. Integrations with Prometheus, Grafana, and Kubernetes are supported natively, providing a one-stop UI for metrics, logs, and traces.Deploy on Nebius
