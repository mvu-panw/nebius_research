# LangChain

GenAI & Agents
Development

LangChain and Nebius partner to power production agents on open models. The langchain-nebius package connects LangChain and Deep Agents to Nebius Token Factory — swap a base URL and model string to run agents on 60+ open models with dedicated endpoints, keeping LangSmith traces intact.

LangChain is also the orchestration layer of the Nebius Agents Blueprint, the Nebius reference architecture for production agents.

See Nebius Blog: Introducting the Nebius Agents Blueprint: Open architecture for production-ready AI Agents.
