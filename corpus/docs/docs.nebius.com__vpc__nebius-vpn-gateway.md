# Nebius VPN Gateway

To establish site-to-site VPN connectivity with external networks in other cloud providers or on-premises data centers, deploy Nebius VPN Gateway, an open-source, VM-based IPsec gateway provided by Nebius Professional Services. This solution supports [Internet Key Exchange version 2](https://en.wikipedia.org/wiki/Internet_Key_Exchange) (IKEv2) with [strongSwan](https://github.com/strongswan/strongswan), [Border Gateway Protocol](https://en.wikipedia.org/wiki/Border_Gateway_Protocol) (BGP) dynamic routing via [FRRouting](https://github.com/FRRouting/frr), active/passive high availability (HA), and includes peer config importers for [Cloud VPN](https://docs.cloud.google.com/network-connectivity/docs/vpn/concepts/overview) in Google Cloud, [AWS Site-to-Site VPN](https://docs.aws.amazon.com/vpn/latest/s2svpn/VPC_VPN.html), [Azure VPN Gateway](https://learn.microsoft.com/en-us/azure/vpn-gateway/vpn-gateway-about-vpngateways) and Cisco IOS.

For details and instructions, see [Nebius VPN Gateway](https://github.com/nebius/nebius-ps-services/tree/main/services/vpngw) on GitHub.
