# Observability in Nebius AI Cloud

Nebius AI Cloud Observability is a unified solution for monitoring the performance, health and behavior of your cloud resources and workloads. It brings alerts, metrics and logs together in a single place, so you can detect issues early and investigate them without switching between tools.

The starting point is the Observability Overview page in the [web console](https://console.nebius.com). It acts as a single point of entry that surfaces the active alerts and links out to detailed views.

The Overview page shows three main sections:

* **Firing alerts**: the alerts that are currently active in your project, so you can immediately spot issues that need attention. For instructions on how to create alerts, see [Setting up alerts](https://docs.nebius.com/observability/alerts.md).

* **Metrics**: key performance indicators for your resources, such as CPU, memory, disk, network and GPU utilization. You can view them on preconfigured dashboards or stream them to [Grafana®](https://docs.nebius.com/observability/metrics/grafana.md) and [Prometheus](https://docs.nebius.com/observability/metrics/prometheus.md) for deeper analysis. For more information, see [Metrics in Nebius AI Cloud](https://docs.nebius.com/observability/monitoring.md).

* **Logs**: the most recent logs from your services, so you can investigate behavior and debug issues. You can also export logs or ingest your own logs for unified analysis. For more information, see [Logs in Nebius AI Cloud](https://docs.nebius.com/observability/logging.md).

Observability is [in preview](https://docs.nebius.com/overview/services.md#service-and-application-stages) and available in all [Nebius AI Cloud regions](https://docs.nebius.com/overview/regions.md).
