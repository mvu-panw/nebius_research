# Container Registry

Container Registry allows you to store and distribute Docker images.

The service is available in all [Nebius AI Cloud regions](https://docs.nebius.com/overview/regions.md).

> **[Getting started](https://docs.nebius.com/container-registry/quickstart.md)**
>
> Create your first registry, push a Docker image to it and run the image

> **[Working with registries](https://docs.nebius.com/container-registry/registries/manage.md)**
>
> Learn how to create and delete registries

> **[Authentication](https://docs.nebius.com/container-registry/authentication.md)**
>
> Set up credentials to access registries from your local machine and CI/CD environments

> **[Copying images between registries](https://docs.nebius.com/container-registry/images/copy.md)**
>
> Transfer Docker images between Container Registry and other registries, such as GitHub Packages
