# SurrealDB

Data
GenAI & Agents

SurrealDB unifies your entire context layer in a single multi-model engine — one query language, one transaction, one deployment. Stop stitching databases together.

SurrealDB is available in the Nebius Marketplace as a partner-managed application on Nebius AI Cloud. Agents and AI applications built on Nebius get a unified context layer — documents, graphs, vectors, and time series in one ACID-compliant engine with SurrealQL — running next to the models it feeds. Application support comes from SurrealDB, infrastructure support from Nebius.
