# Nebius Tunnels pricing

Nebius Tunnels is [in preview](https://docs.nebius.com/overview/services.md#service-and-application-stages) and provided free of charge.

If you run the tunnel agent on a Compute virtual machine (VM), Nebius AI Cloud charges you for the [Compute resources](https://docs.nebius.com/compute/resources/pricing.md) used by the VM.
