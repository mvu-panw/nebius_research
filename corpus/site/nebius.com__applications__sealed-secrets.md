# Sealed Secrets
by Bitnami
InfrastructureSecurity

Sealed Secrets is a Kubernetes controller and tool that allows you to encrypt your Kubernetes Secrets into a SealedSecret resource, which can be safely stored in a public repository. The SealedSecret can be decrypted only by the controller running in the target Kubernetes cluster, ensuring that your sensitive data remains secure.Deploy on Nebius

## Key features

### K8S deployment

Deploy Sealed Secrets on Kubernetes via Helm.

### Encrypted secret manifests

Convert Kubernetes Secrets into encrypted SealedSecret resources for safe Git storage.

### Cluster-bound decryption

Only the controller in the target cluster can decrypt sealed data.

### GitOps-friendly workflow

Manage secrets declaratively in version control without exposing plaintext values.
