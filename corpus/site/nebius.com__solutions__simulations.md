## Purpose-built simulation hardware

Use NVIDIA RTX PRO 6000 Blackwell Server Edition and NVIDIA L40S GPUs paired with leading processors. Built for Isaac Sim, photoreal rendering, and physics simulation without CPU bottlenecks.

## Serverless compute

Provision simulation jobs on-demand and pay only for runtime. Eliminate idle costs. Scale up for a simulation run and auto-terminate on completion.

## Connected sim-to-train pipeline

NVIDIA OSMO Managed by Nebius connects simulation directly to training. Avoid manual handoffs and glue code. Run your entire physical AI learning loop from one control plane.

## What simulation teams can do with Nebius

## Run large-scale SimFarms

Run parallel physics simulations across thousands of virtual environments with NVIDIA Isaac Sim and Isaac Lab. Validate robot behaviors at scale before committing to real hardware.

## Generate synthetic training data

Use NVIDIA Cosmos on Nebius to augment real-world sensor data with physics-grounded synthetic variations: edge cases, adverse weather, and lighting changes.

## Validate before you deploy

Orchestrate your full sim-to-train loop with NVIDIA OSMO Managed by Nebius. Push policies through simulation regression, validate against edge cases, and ship only hardened models to the edge.
