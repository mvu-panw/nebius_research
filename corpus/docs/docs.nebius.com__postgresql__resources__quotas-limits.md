# Quotas in Managed Service for PostgreSQL®

Managed Service for PostgreSQL has quotas on clusters, computing resources and storage. Quotas for vCPU, RAM and storage apply to the values that users set as clusters' vCPU, RAM and storage limits when creating the clusters.

For details on what quotas are and how to manage them, see [Quotas in Nebius AI Cloud](https://docs.nebius.com/overview/quotas.md).

| Quota name | Default value per [region](https://docs.nebius.com/overview/regions.md) |
| :- | :- |
| Clusters | 10 |
| Total vCPUs across clusters | 80 |
| Total RAM across clusters | 320 GiB |
| Network SSD disks total size across clusters | 2 TiB |
