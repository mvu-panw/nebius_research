# JupyterLab® in Nebius AI Cloud

JupyterLab is available as a Kubernetes application in the `eu-north1` and `us-central1` [regions](https://docs.nebius.com/overview/regions.md). You deploy it on a [Managed Service for Kubernetes®](https://docs.nebius.com/kubernetes/index.md) cluster.

## About the application

[JupyterLab](https://jupyterlab.readthedocs.io/en/latest/) is a next-generation web interface for [Project Jupyter](https://docs.jupyter.org/en/latest/). The application provides a flexible and powerful environment for data science, machine learning and scientific computing. It includes [PyTorch](https://pytorch.org/docs/stable/index.html), a popular deep learning framework, and [CUDA®](https://developer.nvidia.com/cuda-zone) support for GPU acceleration.

For more details, see the [application page](https://console.nebius.com/applications) in the web console.

JupyterLab is an open-source product. Its use in source and binary forms is governed by its [license](https://github.com/jupyterlab/jupyterlab/blob/main/LICENSE).

## Getting started

To use the JupyterLab application, [deploy it on a Kubernetes cluster](https://docs.nebius.com/applications/jupyterlab/deploy.md) and [connect to it](https://docs.nebius.com/applications/jupyterlab/connect.md).
