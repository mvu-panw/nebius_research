# Nebius Echo AI assistant

Nebius Echo is an AI assistant that helps you navigate Nebius documentation, explore and manage project resources.

To start the chat, click  **Ask Echo** on any page in the [web console](https://console.nebius.com).

### Core capabilities

| Area | What Echo helps with |
| - | - |
| **Service & feature guidance** | Explains Nebius services, their features, pricing and best-practice usage. |
| **Resource inspection** | Lists or describes existing Nebius resources (virtual machines, storage buckets, etc.) in your projects. |
| **State-changing operations** | Executes actions like creating Nebius resources, or starting and stopping virtual machines (VMs) with explicit approval. |

### Example requests

* *"How do I create a Kubernetes cluster using Nebius CLI?"*
* *"Show all disks not connected to a VM"*
* *"Create a preemptible VM with one H200 GPU and a 100 GiB boot disk"*
