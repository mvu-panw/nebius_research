## Private by default

Every project on Nebius gets its own isolated network. Resources are separated from other tenants from day one, with no additional configuration required.

## From simple isolation to advanced topologies

Define IP ranges, routing rules, and access policies across your entire cloud setup. From basic isolation to advanced custom topologies, the network behaves the way you need it to.

## The layer everything connects to

Virtual Networks provides networking infrastructure to all Nebius AI Cloud resources: compute instances, GPU clusters, and managed services all operate within it.

## Virtual Networks

Virtual Networks give you the structure and controls to define how resources communicate, who can reach them, and how traffic flows in and out of your environment.

## Networks and subnets

Create isolated network segments for your resources. A network in Nebius ensures IP connectivity between resources within it and isolates them from everything outside. Subnets carve that space into addressable segments, each with its own IP range.

## IP addressing and routing

Allocate public and private IP addresses, define CIDR blocks, and manage routing tables per subnet. Set custom routes and next hops for advanced traffic control.

## Security groups

Define firewall rules for your compute instances. Security groups let you control inbound and outbound traffic at the resource level, specifying traffic flows that are allowed or denied.

## Get started

Set up your network environment in the Nebius console, or read the documentation to explore advanced configuration options.
