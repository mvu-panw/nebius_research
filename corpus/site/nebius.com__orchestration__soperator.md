## Questions and answers

What is Slurm?

Slurm is an open source, fault-tolerant and highly scalable cluster management and job scheduling system for large and small Linux clusters.
Learn more​

Why is Slurm good for distributed training?

Slurm can schedule thousands jobs per seconds across thousands of nodes. With topology-aware resources allocation, it can significantly increase the efficiency of the distributed model training.

Does Managed Soperator require any infrastructure configuration?

No, you can create a Slurm cluster in a few clicks via the web console. All necessary infrastructure component and services will be provisioned and deployed automatically.

Is Managed Soperator a paid service?

Yes, you pay only for compute usage. We don’t charge you for the Soperator software.

Should I pay for Managed Service for Kubernetes when using Manage Slurm?

No, the cost for Managed Kubernetes is $0. However, the service is activated when you have deployed the Managed Slurm.

What’s the difference between Managed Soperator and Soperator?

Soperator is a functional part of the Managed Soperator service. It allows us to seamlessly run Slurm in Kubernetes clusters.

Does Soperator on Nebius ready to use for training out of the box?

Yes, all necessary components (including NVIDIA drivers) are pre-packed. By using Managed Soperator you can deploy cluster from scratch in 20-30 minutes.

Can I use Soperator in other public cloud or on-premises?

Yes. In this case you should go to this GitHub repo and download the open-source version of the product.
