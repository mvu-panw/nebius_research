# Stable Diffusion web UI
by AUTOMATIC1111
Serving

The Stable Diffusion web UI, developed by AUTOMATIC1111, is an easy to use browser interface for one of the most popular text to image deep learning models. Powered by Gradio, the UI features basic and advanced Stable Diffusion capabilities, such as original txt2img and img2img modes, outpainting, inpainting and upscaling, weighted prompts and prompt matrices, loopback, and many more.Deploy on Nebius
