# How to sign up for Nebius AI Cloud

To sign up for Nebius AI Cloud:

1. [Create a Nebius AI Cloud account](#create-a-nebius-ai-cloud-account).
2. [Set up billing](#set-up-billing).

## Create a Nebius AI Cloud account

1. Open the [Nebius AI Cloud web console](https://console.nebius.com).

2. Select whether you want to use a Google, GitHub or Microsoft account to work with Nebius AI Cloud.

   After the sign-up, you log in to the web console with the selected account.

3. Enter your credentials.

4. Allow Nebius AI Cloud to use your Google, GitHub or Microsoft account.

5. On the **Contact details** page that opens, enter your name and email. Confirm that you agree with the [Nebius AI Cloud Terms of Use](https://docs.nebius.com/legal/terms-of-use.md).

After that, the web console opens. A [project](https://docs.nebius.com/iam/overview.md#projects) and a [tenant](https://docs.nebius.com/iam/overview.md#tenants) are automatically created for you. Together, they form a working environment where you can create resources and run ML/AI training and inference tasks.

## Set up billing

Specify details for payment in the **Billing** section. If you skip this step, you will be prompted for billing details when you create the first resource.

To set up billing:

1. Go to [Billing](https://console.nebius.com/billing/create) in the web console.
2. Select whether you pay for resources on behalf of a company or as an individual:

   **Company**

   1. Specify the required information:

      * Country where the company is based
      * Billing address
      * Company name
      * Tax ID or VAT ID (A tax ID identifies your company for general tax purposes, while a value-added tax (VAT) ID confirms that your company is also registered to handle VAT or goods-and-services tax (GST).)

   2. In the **Payment details** section, select whether you want to [pay by card](https://docs.nebius.com/signup-billing/payments/card.md) or [make bank transfers](https://docs.nebius.com/signup-billing/payments/bank-transfers.md).

   3. If you select the card option, add the card details. After you submit them, Nebius charges \$25 and adds this amount to your account balance.

   4. Confirm that you agree to the [Nebius AI Cloud Services Agreement](https://docs.nebius.com/legal/agreement.md) and that you have read the [Privacy Policy](https://docs.nebius.com/legal/privacy.md).

   5. Click **Save billing details**.

   6. If you intend to make bank transfers, finish the billing configuration. In the window that opens, select one of two options:

      * **Contact sales**: Submit a request to make bank transfers. In this request, specify billing details for the Nebius sales team.
      * **I already have a personal manager**: Copy your contract ID and pass it along to your Nebius manager.

      > [!NOTE]
      >
      > For companies from Israel, bank transfers in Israeli shekels (ILS, ₪) are the only payment method available.

   **Individual**

   1. Select your country of residence.
   2. Add the card details.

   3) Specify your billing details.
   4) Confirm that you agree to the [Nebius AI Cloud Services Agreement](https://docs.nebius.com/legal/agreement.md) and that you have read the [Privacy Policy](https://docs.nebius.com/legal/privacy.md).
   5) Click **Save billing details**.
