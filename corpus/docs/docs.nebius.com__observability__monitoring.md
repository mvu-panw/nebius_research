# Metrics in Nebius AI Cloud

Metrics in Nebius AI Cloud are available in several forms:

* Preconfigured [dashboards](https://docs.nebius.com/observability/dashboards.md) in the web console show key metrics for each resource.
* The full range of metrics is available via [Prometheus](https://docs.nebius.com/observability/metrics/prometheus.md) and [Grafana®](https://docs.nebius.com/observability/metrics/grafana.md) integrations. You can filter and visualize the metrics you want to track.

You can also set [alerts](https://docs.nebius.com/observability/alerts.md) that trigger when metrics cross the specified thresholds.
