# Voxel51

Data
Development

Voxel51 builds the open-source FiftyOne platform for AI data curation, visualization, and annotation. Voxel51 is a technology partner in the Nebius cloud for robotics and physical AI, announced with NVIDIA.

FiftyOne’s data curation, annotation, and auto-labeling workflows run on Nebius GPU clusters, and the companies built a joint synthetic-data-generation pipeline supporting Porsche’s autonomous-driving workflows. For vision and physical AI teams, Voxel51 covers data quality while Nebius provides the compute underneath.

See Nebius announcement featuring Voxel51: Nebius teams with NVIDIA to build cloud for robotics and physical AI.
