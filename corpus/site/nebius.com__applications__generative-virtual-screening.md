# Nvidia Blueprint Generative Virtual Screening
by Nvidia
GenAI & Agents

The NVIDIA Blueprint: Virtual Screening demonstrates a streamlined virtual screening workflow that leverages generative AI and GPU accelerated NIM microservices to predict protein structures, generate optimized small molecules, and perform protein ligand docking—built for speed, flexibility, and scientific rigor. This reference framework simplifies deployment via containerized microservices (e.g., MSA Search, OpenFold2, GenMol, DiffDock), enabling researchers to accelerate the hit to lead pipeline with state of the art tools. For more info of the Blueprint, visit the blueprint card.
