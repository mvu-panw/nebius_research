## Key features

### Low-latency caching

Serve frequently accessed data with sub-millisecond response times.

### Vector search

Build semantic search, recommendations, and RAG retrieval workflows.

### Agent memory

Store session context, preferences, and recall data for AI applications.

### Real-time data structures

Use streams, pub/sub, JSON, time series, and probabilistic structures.
