# How to use a promo code

A promo code grants you free credits for using Nebius AI Cloud resources. You can receive a promo code from Nebius as part of a special offer.

Usually, a promo code comes with an expiration date. Make sure to apply it before that date to receive the credits.

You cannot use a promo code for an outstanding invoice. That invoice must still be paid.

To use promo codes, you should be registered in Nebius AI Cloud. Make sure to [sign up](https://docs.nebius.com/signup-billing/sign-up.md): create an account and specify details for payment. Once you add a bank card, Nebius charges \$25 and adds this amount to your account balance. After that, you can apply promo codes.

To apply a promo code:

1. Go to the [Billing](https://console.nebius.com/billing/) section of the web console.

2. Click  **Apply promo code**. If you do not see the button, check that you specified details for payment.

3. Enter your promo code and click **Apply promo code**.

Once your promo code is applied, your balance increases by the corresponding amount.

You can check if the promo code was applied in the [transactions list](https://console.nebius.com/billing/transactions).
