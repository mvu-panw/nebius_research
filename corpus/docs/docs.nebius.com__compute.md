# Compute

Compute allows you to create and manage virtual machines (VMs). These VMs function similarly to your local machine but are hosted in the cloud. You can connect to them and use their GPUs and other computing resources in your ML/AI workloads.

In the [web console](https://console.nebius.com), the **Virtual machines** page has two tabs:

* **Standalone VMs**
* **Kubernetes nodes**

The service is available in all [Nebius AI Cloud regions](https://docs.nebius.com/overview/regions.md).
